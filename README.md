# Yürüyen Merdiven Sol Şerit Kabahati

Bu depo, insanlığın en kadim suçlarından birini ele alır: **yürüyen merdivenin solunda dikilmek.**

Sağ şerit dinlenmek içindir. Sol şerit, geç kalanların, randevusu olanların ve içinden acele fışkıranların kutsal koridorudur. Sen ise çantanı sol tarafa koymuş, telefona bakıyor, arkandaki üç kişiyi metafizik bir tıkanıklığa mahkum ediyorsun. Bu yazılım o anı resmi evraka çevirir.

Patates yoktur. Ne benzetme, ne metafor, ne de yan ürün. Merdiven patates yemez.

## Ne işe yarar

Hiçbir şeye. Ama çalışır.

`python sol_serit_mahkemesi.py` dediğinde:

- duruşu rastgele bir kabahat maddesine bağlar,
- arkadaki kişi sayısına göre manevi tazminat hesaplar (birimi özür),
- sağa geçiş protokolü üretir,
- çıkış kodu her zaman `0`dır, çünkü merdiven asla kaybetmez.

## Kurulum

```bash
git clone https://github.com/Tentivory/yuruyen-merdiven-sol-serit-kabahati.git
cd yuruyen-merdiven-sol-serit-kabahati
python sol_serit_mahkemesi.py
```

Python 3 yeter. Bağımlılık yoktur. Vicdan opsiyoneldir.
